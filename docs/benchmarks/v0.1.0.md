## Token and Measurement Notes

> [!NOTE]
> Token estimates are computed roughly from returned UTF-8 payload bytes divided by 4 (`bytes / 4`). They represent local payload size approximations, not reported token counts from any live language model tokenizer. Save and indexing throughput reflects atomic filesystem persistence (`os.replace` and `os.fsync`) and SQLite FTS5 transaction commits on local storage.
